# 분석 보고서 (team-analyst, 2026-11-11)

## 1. 모놀로그가 검증을 통과한 이유 (원인 확정)
`src/agents/scriptAgent.ts` `validateMessages`는 **개수(>=18)와 "상대 닉네임 종류 >=3"만** 본다 (L28-33).
- 상대 3명이 각 1~2줄만 말해도 통과. 발화 비중/연속 발화/반응 비율을 안 봄.
- 문제 런(콜센터 푸념글): 나 17/23줄(74%), 나 연속 최대 5줄, 상대 3명은 줄당 2줄 추임새("헐 벌써?!", "토닥토닥") -> 검증 통과.
- `cleanMessages`는 sender/text 형식만 거른다(문제 없음). 폴백(`getFallbackScript`)은 검증 3회 실패 시에만 작동, 이번엔 해당 없음.
- 품질 붕괴 지점은 **스토리 선정 80% + 각색 20%**: 원문이 "나 일 못하는 이유 나열(푸념/독백)"이라 대화 구조가 없고, 프롬프트의 "원문 사건 순서 유지" 규칙이 독백 구조를 그대로 복제시킴. 플래너는 "웃음 포인트 뚜렷" 조건이 있어도 후보가 전부 약하면 -1 대신 그나마 나은 글을 고름(후보 풀 문제).

## 2. 소스 공급 (네이트판)
- 랭킹 페이지: 항목 70개/일(스냅샷 1회). 본문 80자 이상 51개.
- 제목/본문 수동 분류: 연예인/아이돌 가십 ~35, 시댁/결혼/부부 갈등 ~12, 사진/질문형 짧은 글 다수, **가볍고 웃긴 일상 썰 약 0~2개**. 세이프+웃김은 **하루 0~1개**가 현실적. `limit=8`로 앞 8개만 보므로 대부분 가십/갈등글이고 에이전트가 억지로 고르게 됨.

- **중대 리스크 (robots.txt)**: `pann.nate.com/robots.txt`는 `User-agent: *` `Disallow: /`, 허용은 구글/빙/다음 등 검색봇뿐이고 **ClaudeBot/GPTBot 명시 차단**. 현재 Mozilla UA 스크래핑은 robots 위반 소지. 일 1회 소량이라도 약관/저작권(타인 창작글 각색+출처표기만으로는 면책 아님) 리스크가 있음. 수익화(쿠팡)까지 붙으면 더 위험.

## A5. HTML 안정성 점검 (dedupe key / 댓글)
- post id: URL `/talk/<id>` 숫자, `og:url`(`https://pann.nate.com/talk/<id>`) 및 목록 `<a href="/talk/<id>">` 모두 일치. 단조 증가하는 정수라 dedupe 키로 안정적(`?page=1` 같은 쿼리만 제거하면 됨). 큐 slug/used_sources에 id 사용 문제 없음.
- 본문: `id="contentArea"`는 5개 페이지 모두 존재(현 `indexOf('</div>')` 방식은 본문 내 `<div>`가 있으면 일찍 잘릴 위험, 이미지만 있는 글은 본문 17자 -> 길이 필터로 제거됨). 본문 첫머리에 `id="contentArea">` 문자열이 섞여 나옴(pann_out.json sourceText에서 확인) -> `>` 이후부터 취하도록 정리 필요.
- 제목/메타: `og:title`(` | 네이트 판` 접미사), `og:description`(앞 100자), `<span class="date">`. 
- 댓글: 서버 렌더됨. 일반 댓글 `#replyArea` 내부 `dl.cmt_item`, 텍스트 `dd.usertxt span`, 추천수 `dd.n_good`(id `R_cnt_<cmtId>`), 반대 `n_bad`, 작성자 `span.nameui`. 베스트 댓글 영역 `#bepleDiv`는 샘플 40여 개 중 비어 있음(추천이 낮은 글) -> **commentsTop은 `n_good` 내림차순 정렬로 직접 산출**해야 함. 한 페이지에 전체가 아니라 일부만 포함될 수 있음(글마다 1~23개 확인). 댓글 수가 0~2개인 글이 다수라 "댓글이 ㅋㅋ 위주" 기준(재미 5번)은 데이터 부족으로 자주 0점 -> 가점 항목으로 완화 권장.
- 취약점: 정규식 파싱이므로 `class="subject"`/`cmt_item`/`contentArea` 이름이 바뀌면 깨짐; 후보 0개 시 비0 종료로 감지 필요.
